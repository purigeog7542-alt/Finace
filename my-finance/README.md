# MY FINANCE - Personal Finance Cloud Web App

ระบบจัดการรายรับ รายจ่าย และกระแสเงินสดส่วนบุคคล (Responsive Web App) รองรับการใช้งานบน iPhone, iPad และ Desktop ด้วยโทนสี Dark Mode และเชื่อมต่อฐานข้อมูลแบบเรียลไทม์ผ่าน Supabase Cloud

## คุณสมบัติหลัก
- **Dashboard ภาพรวมการเงิน**: แสดงยอดเงินคงเหลือสะสม, รายรับรวม, รายจ่ายรวม และเงินออมสุทธิ พร้อมกราฟวิเคราะห์กระแสเงินสด
- **บันทึกรายการรวดเร็ว (+ Add Record)**: เพิ่มรายรับ รายจ่าย และโอนเงินระหว่างบัญชี
- **จัดการประวัติรายการ (Transactions)**: ค้นหา กรองตามประเภท/หมวดหมู่/ช่วงเวลา และแก้ไขหรือลบย้อนหลัง
- **จัดการบัญชี (Accounts)**: รองรับหลายบัญชี เช่น บัญชีธนาคาร เงินสด และคำนวณยอดแยกตามบัญชี
- **งบประมาณรายเดือน (Budgets)**: ตั้งงบประมาณแยกหมวดหมู่พร้อมแถบแสดงเปอร์เซ็นต์การใช้งาน
- **เป้าหมายการออม (Savings Goals)**: ติดตามเป้าหมายเงินสำรองฉุกเฉินและการออมระยะยาว

## ขั้นตอนการติดตั้งและใช้งาน
1. ติดตั้งแพ็กเกจ:
   ```bash
   npm install
   ```
2. ตั้งค่าฐานข้อมูลบน Supabase:
   - นำคำสั่งในไฟล์ `schema.sql` ไปรันใน **SQL Editor** ของ Supabase
3. ตั้งค่า Environment Variables:
   - คัดลอกไฟล์ `.env.example` เป็น `.env.local` แล้วกรอก `NEXT_PUBLIC_SUPABASE_URL` และ `NEXT_PUBLIC_SUPABASE_ANON_KEY`
4. รันโปรเจกต์:
   ```bash
   npm run dev
   ```
